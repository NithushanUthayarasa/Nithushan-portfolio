## Featured Projects

### ContextIQ — RAG-Powered Document Intelligence System
A multi-document RAG system that generates grounded answers from uploaded documents using semantic and hybrid retrieval.

I designed and implemented the complete RAG pipeline, including document extraction, chunking, embeddings, retrieval, reranking, answer generation, source citations, and retrieval evaluation. The system integrates Google Gemini, ChromaDB, BM25, and Streamlit.

**Technologies:** Python · RAG · Gemini · ChromaDB · BM25 · Streamlit  
[Repository](https://github.com/NithushanUthayarasa/ContextIQ-RAG-System) · [Live Application](https://contextiq-ai-rag.streamlit.app/)

### Automated Manufacturing Inventory Coordinator
A collaborative AI-assisted manufacturing system for inventory management, procurement, quality assurance, and workflow automation.

My work focused primarily on Quality Assurance and Floor Worker AI functionality. I contributed to supplier, budget, purchase-order, and material validation, LangGraph-based AI workflows, inventory data extraction, low-stock processing, and testing AI-integrated workflows across the application.

**Technologies:** Python · FastAPI · LangGraph · ASP.NET Core · React · Flutter · PostgreSQL

### Garbage Image Classification — CNN & Transfer Learning
A computer vision system that classifies waste images across 10 categories using deep learning.

I prepared and processed the dataset, trained CNN and transfer-learning models, and evaluated performance using accuracy, precision, recall, and F1-score. The final model achieved approximately 88.6% test accuracy.

**Technologies:** Python · TensorFlow/Keras · CNN · Transfer Learning · Computer Vision  
[Repository](https://github.com/NithushanUthayarasa/SmartWaste-Image-Classification-CNN)

I worked on data preprocessing, exploratory data analysis, feature engineering, model training, model comparison, hyperparameter tuning, cross-validation, and decision-threshold optimization using multiple gradient boosting algorithms.

**Technologies:** Python · Scikit-learn · CatBoost · XGBoost · LightGBM
