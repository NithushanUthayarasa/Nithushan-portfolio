## 🚀 Featured Projects & Contributions

### 1. ContextIQ — RAG-Powered Document Intelligence System
- **Links:** [GitHub Repository](https://github.com/NithushanUthayarasa/ContextIQ-RAG-System) | [Live Application](https://contextiq-ai-rag.streamlit.app/)
- **Overview:** Multi-document intelligence system generating grounded answers from uploaded documents using RAG.
- **My Contributions:**
  - Designed and built the complete RAG pipeline (extraction, chunking, embedding, retrieval, generation).
  - Integrated Google Gemini embeddings and LLMs with ChromaDB vector storage.
  - Added hybrid retrieval (BM25 + vector search), reranking, and source citations.
  - Implemented quantitative evaluation (Hit@K, Recall@K, MRR) and built the Streamlit UI.
- **Technologies:** Python, RAG, Gemini, ChromaDB, BM25, Streamlit
